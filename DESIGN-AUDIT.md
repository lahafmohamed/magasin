# DESIGN-AUDIT.md — Design System & UX Audit

Audited 2026-07-29 (4 parallel scans: tokens, component library, UX patterns, accessibility/responsive). Companion to [AUDIT.md](AUDIT.md) (code quality) and [FEATURE-AUDIT.md](FEATURE-AUDIT.md) (capability gaps). All file references relative to `frontend/src/`.

**Scope:** 138 `.ts/.tsx/.css` files · 46 pages · 21 shared components · 32 `components/ui` primitives.

**Score at audit time: 61/100.** The primitives layer is genuinely good (avg 7.5/10, some 9–10s); the problem was *adoption* — most primitives were used by a third of the pages that needed them, and the token layer had one structural defect (semantic colors not theme-aware) that silently degraded dark mode across ~128 call sites.

> **Premise correction (fixes CLAUDE.md/lore):** Radix **is** installed and used — 7 `@radix-ui/*` packages back `dialog`, `dropdown-menu`, `label`, `popover`, `scroll-area`, `select`, `separator`. Only `tabs.tsx` and `checkbox.tsx` are deliberately hand-rolled.

**Frontend bug found in passing** — the Avoirs UI used `avoir_type: 'remise'`, but the DB CHECK constraint allows `retour | echange | remise_commerciale | erreur`. The filter option could never match a row, and `echange` was missing from the UI entirely.

## 1. What is healthy (keep doing this)

- `window.confirm`/`alert`: **0** in the codebase; `useConfirm()` adopted on 13 pages, 23 gated sites.
- Raw `<select>` bypass: **0** — 100% Radix Select adoption; all 61 `SelectTrigger`s labeled.
- Hand-rolled tab bars: **0** — `ui/tabs.tsx` is the best primitive in the repo (10/10: full ARIA tablist, roving tabindex, ←/→/Home/End).
- Charts fully tokenized — all 5 recharts pages use `lib/chartColors.ts`; zero raw hex/palette in any `fill`/`stroke`; dark chart palette separately tuned.
- Hardcoded hex: 19 occurrences, **all** legitimate print-CSS exceptions.
- `ui/dialog.tsx` + `confirm-dialog.tsx`: full pass on focus trap, Escape, `aria-modal`, focus restore, initial focus. 40 `DialogContent` blocks, 0 missing `DialogTitle`.
- `StatusBadge`: no color-only state — all 25 statuses carry French text labels.
- French UI copy: zero English leaks in labels/buttons/toasts.
- No global `outline: none`; `prefers-reduced-motion` handled globally; no fixed-width viewport breakers (`min-w-[8xx]`: 0).

## 2. P0 — actively harms users

### 2.1 Fetch failures render as fake data (21 pages)
Only 17 files hold error state. Pages that catch a load failure and only toast/console leave a UI indistinguishable from real data:

- **`pages/Tresorerie.tsx:28`** — worst: `.catch(() => toast.error(...))`, `data` stays null, page renders `soldeNet = 0 − 0` **as if the treasury were genuinely zero**.
- `pages/Dashboard.tsx:291` — whole dashboard renders zeroed KPIs on failure.
- Truly silent (no toast, no UI): `AvoirDetail.tsx:36`, `CommandeDetail.tsx:91,144,165`, `FactureDetail.tsx:86`.
- `DocumentListPage.tsx:158` — `fetchStats().catch(() => {})`: stats tiles fail invisibly on every doc-list page.
- Rest: ClientAnalytics, DemandesList, Reapprovisionnement, Avoirs, Inventaire, Receptions, CaisseV2, FacturesFournisseur, DepensesV2, ParametresFinance, CompanySettings, StockTransfers, UserManagement, DemandeDetail/Form, BonLivraisonDetail, DevisDetail.

**Fix:** adopt `<QueryState>` (already exists, 9/10) — currently 15/45 pages. Reference done-right: `Tiers.tsx:78-82`, `StockValuation.tsx:87-89`.

### 2.2 Unconfirmed destructive delete
**`components/AttachmentPanel.tsx:97`** — `onClick={() => onDelete(a.id)}` → permanent attachment delete, no confirmation, embedded on every document detail page. Also: `Inventaire.tsx:269` and `DevisDetail.tsx:151` use bespoke delete dialogs while sibling code in the same file/entity uses `useConfirm` — two confirmation UIs per feature. `Inventaire.tsx:296-302` bulk delete swallows per-item failures.

### 2.3 Semantic color ramps are not theme-aware (structural token defect)
`tailwind.config.js:18-37` defines `success/warning/danger/info` as **literal hex** — no `--success/*` CSS vars exist in `index.css`. Every `text-success-700` renders identical dark-green in dark mode. **128 lines carry a `-600/700/800/900` semantic shade with no `dark:` sibling** (of 594 semantic usages). Worst files: `TiersDetail` (17), `Reporting` (16), `GeneralLedger` (10), `PaymentStatusBar` (9 — `bg-danger-50` renders a near-white block on dark surfaces).

**Fix (highest-leverage single change):** convert the 4 ramps to `hsl(var(--success-N))` + `.dark` overrides in `index.css` → ~128 manual `dark:` patches become unnecessary.

Related dark-mode breaks: the 4 print-preview modals each have a `bg-white … print:hidden` sticky **screen** toolbar — white-on-white in dark mode (`AvoirDetail:224`, `BonLivraisonDetail:226`, `DevisDetail:236`, `FactureDetail:674`).

### 2.4 Raw server errors reach users (56 sites)
`err?.response?.data?.error || …` is the dominant toast pattern, unsanitized — SQL constraint names reach users. Worse, 7+ sites fall back to `error.message`, surfacing axios internals ("Network Error", "Request failed with status code 500"): `CaisseV2.tsx:305,346,366,423,459`, `Login.tsx:46`, `ui/query-state.tsx:32`. Exactly **one** file defends (`Comptabilite.tsx:200-203` regex-guards `violates|constraint`). **Fix:** one shared `getErrorMessage(err)` util with the Comptabilite guard, used everywhere.

### 2.5 Unbounded fetch fan-out
**`pages/Avoirs.tsx:118-133`** — fetches page 1, reads `totalPages`, then `Promise.all` fires N−1 parallel requests for the entire table, paginates client-side. Also all-rows fetches: `StockTransfers.tsx:104` (entire product catalog into a form), `UserManagement.tsx:74` (hardcoded 100, silently truncates user #101), `DemandesList`, `StockLocations`, `Receptions`, `Comptabilite` (date-bounded only).

## 3. P1 — system erosion (primitives exist, pages bypass them)

| Concept | Canonical | Adoption | Bypass |
|---|---|---|---|
| Spinner | `ui/loading.tsx` | **1 use** (`UserManagement:398`) | **70 hand-rolled** — `Loader2` ×56, `RefreshCw` ×7, CSS-ring div ×7 in 3 sizes/colors. Worst inconsistency in the repo. |
| Page header/h1 | `ui/page-header.tsx` (docstring says "toutes les pages doivent l'utiliser") | 11/45 pages | **40 raw `<h1>` in 14 distinct class combos** (size/weight/tracking drift on 3 axes) |
| Doc-list template | `DocumentListPage.tsx` | 3/~14 (Factures, Devis, BL) | `Avoirs` is a near-verbatim clone (copies the `/` shortcut hint); `Commandes`, `DemandesList` next closest |
| Fetch gate | `ui/query-state.tsx` | 15/45 | 7 skeleton hand-rolls + 14 bare-spinner early-returns + 8 pages with nothing |
| Empty state | `ui/empty-state.tsx` | 15 pages | 24 bare `<p>Aucun…</p>` sites (Reporting ×6 identical); **5 tables with zero empty guard** (`ParametresFinance:130`, `FactureDetail:541`, `DemandeDetail:289,328`, NouvelAvoir) |
| Badge | `ui/badge.tsx` + `StatusBadge` | 24+16 importers | 13 hand-rolled pill sites; `Commandes.tsx:282` hardcodes `bg-blue-500` when the `info` variant exists |
| Table | `ui/table.tsx` / `responsive-table` | ResponsiveTable: 7/39 table files | 17 raw `<table>` in 12 files; `Inventaire.tsx:1032` re-implements Table's classes verbatim inline |
| Stats tiles | `ui/stats-bar.tsx` | 3 pages + DocumentListPage | 14+ pages hand-roll grid-of-Cards |
| Modal | `ui/dialog.tsx` | 22 files | 8 `fixed inset-0` hand-rolls: **4 copy-pasted print-preview overlays** (AvoirDetail/BLDetail/DevisDetail/FactureDetail — extract one component), 2 catalog drawers (Commandes/CommandeDetail), App help modal, Sidebar drawer — all without focus trap/Esc(partial)/`aria-modal` |

### 3.1 Money formatting — one function, four names, two currencies
`utils/format.ts` exports `formatCurrency` (canonical) + deprecated `formatFCFA`/`formatXOF`. Import split: `formatCurrency` ×16 pages, `formatFCFA` ×8, `formatXOF` ×5, `formatFCFA as formatXOF` ×7; `FactureDetail.tsx:22` imports both. **`DevisDetail.tsx:183`** bypasses with raw `Intl.NumberFormat` — the only place in the app rendering "XOF"; everywhere else shows "FCFA". Two more private impls: `GeneralLedger.tsx:72`, `print-layout.tsx:56`. The `devise` param + CompanySettings currency field are dead config — zero call sites pass it.

### 3.2 Dates
Shared `formatDate`/`formatDateShort` used by 8 pages; **41 inline `toLocaleDateString('fr-FR')`** across 19 pages + 8 inline datetime variants + 2 local reimplementations (`CaisseV2:466`, `CaisseHistorique:44`). Gap: no shared `formatDateTime` export. Locale itself is consistent (fr-FR everywhere).

### 3.3 Forms
- react-hook-form + zod: 6 pages (the create-document flows). Manual `useState` forms: 18 pages.
- **7 manual forms submit with zero validation** — `StockLocations:100`, `UserManagement:125` (`parseInt` → NaN), `Employes:171` (`parseFloat` → NaN posted), `Inventaire:208`, `CompanySettings:84`, `Receptions:129`, `CommandeDetail:119`.
- Only 3 pages show inline field errors (`Tiers`, `ChangePassword`, `Profil`); everything else = disappearing toast.

### 3.4 Layout drift (no page shell)
`Layout.tsx:57` `<main>` provides zero padding, so every page re-declares: `p-3 sm:p-6` ×22, `p-4` ×24, `p-5` ×12, `p-6` ×8, +3 more variants; **19 distinct root-container class combos**; max-width drifts (6xl/5xl/3xl/full/none). Card padding overridden 74× (`p-4` ×21, `p-0` ×21…) — the `p-6` default is effectively wrong; de-facto standard is `p-4`. **Fix:** one `<PageShell>` (or padding in Layout) + change Card default.

### 3.5 Pagination
Shared component on 13 pages, but: its **4 chevron buttons have no `aria-label`** (inherited by every list page); `Employes:370` and `Tiers:381` omit `onLimitChange` so "Lignes par page" silently disappears; page state is `useState` on 10 pages (lost on back-nav) vs URL state only in DocumentListPage; default limits split 20 vs 50.

## 4. P2 — accessibility

- **54 orphan inputs** (no id/label/aria-label): dominant pattern = in-table editable cells (qty/price lines in `Commandes`, `CommandeDetail`, `NouveauBonLivraison`, `NouvelleFacture`, `ParametresFinance` ×7). Screen readers announce "edit, blank". Plus 4 bare unlabeled checkboxes (`CaisseAudit:173`, `Employes:444`, `ParametresFinance:148,232` — also should be the `Checkbox` primitive). GlobalSearch input is placeholder-only.
- **21 unnamed icon-only buttons** (of 71): worst = `ui/pagination.tsx` (4, shared), `DemandeForm` (5), NotificationBell (2).
- **Hand-rolled modals** (App help `App.tsx:106`, Sidebar drawer `Sidebar.tsx:143`): no focus trap, no role/`aria-modal`, no focus restore; drawer also lacks Escape + scroll lock.
- **Announcements:** 1 `aria-live` in the whole tree (`Reporting:417`); `LoadingScreen` (the Suspense fallback for every lazy route) has no `role="status"`/text; 0 `aria-busy` anywhere; NotificationBell badge updates silently; SSE connection loss fully silent (`useSseNotifications.ts:56`).
- **No skip-to-content link**; sidebar precedes `<main>` in DOM on every route; `<main>` has no id.
- **Touch targets: 98% of 373 buttons < 44px.** Button scale caps at `lg: h-10` (40px). 21 sites ≤ 28px (NotificationBell `h-5/h-6`, DemandeForm 28px steppers at 4px gaps, unnamed). Pagination = four 32px targets at 4px mobile gap.
- **Type size on financial data:** trial-balance totals + running balances at 12px (`Comptabilite:392-394,444-446`); `Reste dû` at 12px muted (`FacturesFournisseur:509`); **10px `role="alert"` validation errors** (`NouveauDevis:564,586`, `NouvelleFacture:644,674`); Sidebar nav-category headings 10px at `/70` opacity (~3.4:1).
- Focus: one genuine unreplaced `focus:outline-none` — `NouvelleFacture.tsx:615` line-qty input (also unlabeled).
- `badge.tsx` uses `focus:` ring not `focus-visible:`; `bg-warning` + `text-white` is a contrast risk.
- Responsive: 32 table files degrade to sideways scroll on mobile (ResponsiveTable: 7 adopters); heaviest multi-table scrollers: Comptabilite ×4, GeneralLedger ×3.

## 7. Remaining backlog

Items 1–8 and 10 of the original priority list landed on 2026-07-29 (see §0). What is left:

1. **Money/date util unification** (P1) — codemod the 3 deprecated aliases (`formatFCFA`, `formatXOF`, `formatFCFA as formatXOF`) to `formatCurrency`; fix `DevisDetail.tsx:183`, the only screen rendering "XOF" instead of "FCFA"; fold `GeneralLedger`'s private `formatNum` and `print-layout`'s `fmtMoney` into the shared util; add a `formatDateTime` export and codemod the 41 inline `toLocaleDateString('fr-FR')` calls. Decide whether `formatCurrency`'s `devise` param + the CompanySettings currency field should be wired up or dropped — today they are dead config.
2. **DocumentListPage migration, round 2** (P1) — `Commandes.tsx` and `DemandesList.tsx` are the remaining near-clones. The hook now supports URL-backed `extraFilters`, which was the blocker. `DemandesList` also still uses a raw `<table>`.
3. **Page shell** (P2) — one `<PageShell>` (or padding in `Layout`) to collapse the 6 competing page paddings and 19 root-container variants; change `Card`'s `p-6` default to `p-4` (overridden 74 times today); migrate the remaining raw `<h1>`s to `PageHeader`.
4. **Input error state** (P2) — `Input`/`Textarea` have no invalid state, which is why only 3 pages show inline field errors and everything else uses a disappearing toast. Add `aria-invalid` styling, then convert the toast-only validators.
5. **Identity color tokens** (P2) — supplier-orange, client-blue and compensation-purple have no names, which is why ~30 raw-palette sites exist. `TiersDetail.tsx:398,973` hand-roll a full purple button skin that should be a Button variant.
6. **Responsive tables** (P2) — `ResponsiveTable` has 7 adopters out of 39 table-rendering files; 17 raw `<table>` elements remain (`Inventaire.tsx:1032` re-implements the primitive's classes inline). Comptabilite (4 tables) and GeneralLedger (3) are the worst mobile offenders.
7. **Touch targets** (P2) — `Button`'s scale tops out at `lg: h-10` (40px); no variant reaches the 44px WCAG reference. 21 sites are ≤28px.
8. **In-table input labels** (P2) — the bulk of the remaining orphan inputs are editable qty/price cells; they need `aria-label`s naming the row + column.
9. **12px financial data** (P3) — trial-balance totals and running balances render at `text-xs` (`Comptabilite.tsx:392-394,444-446`); consider bumping the accounting tables to `text-sm`.
